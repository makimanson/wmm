====================================================
 ENGLISH VERSION
====================================================

Thank you for downloading WMM!

WMM is a wallpaper manager for multi-monitor setups on Linux and Windows,
with support for Cinnamon, GNOME Shell, KDE Plasma 6, MATE and XFCE.

SUPPORTED ENVIRONMENTS
----------------------

  - Cinnamon:       Full support (X11)
  - GNOME Shell:    Full support (versions 45 to 51)
  - KDE Plasma 6:   Full support
  - MATE:           Full support (X11)
  - XFCE:           Full support (XFCE 4.20 / X11)
  - Windows:        Full support
  - macOS:          In development

QUICK INSTALLATION
------------------

LINUX

1. Open a terminal in the folder containing wmm-install.sh.

2. Run:

       chmod +x wmm-install.sh
       ./wmm-install.sh

   The installer detects your desktop environment, checks dependencies
   and offers to install any missing ones.

3. After installation, enable or launch WMM:

   - Cinnamon:
     Restart your session, then enable "WMM Manager" in Applets settings,
     or launch it from Menu > Graphics.

   - GNOME Shell:
     Restart your session, then enable "WMM Manager" in Extensions,
     or launch it from Applications > WMM.

   - KDE Plasma 6:
     On Plasma 6.6.6 or later, the installer restarts Plasma Shell.
     On older versions, restart your session. Launch WMM Manager from
     Menu > Graphics.

   - MATE:
     Add "WMM Manager" using Add to Panel, or launch it from
     Menu > Graphics.

   - XFCE:
     Launch WMM Manager from Menu > Graphics.

WINDOWS - OPEN-CODE

1. Download the WMM source code from GitHub and extract it to a folder.

2. Run wmm-install.cmd from the main folder, select Install and confirm.

3. If wmm-runtime.zip is missing, the installer offers to download it
   from GitHub when available. You can also download it separately and
   place it next to wmm-install.cmd before starting.

4. Follow the prompts. Once installed, launch WMM Manager from the
   Windows Start menu. You can also choose a desktop shortcut and
   automatic startup.

WINDOWS - COMPILED VERSION

1. Download WMM-Manager-Setup from the corresponding release.

2. Run the installer and follow the setup wizard.

3. Launch WMM Manager from the Start menu or its shortcut.

   All required components are included; no separate runtime download
   is needed.

For updates, reinstallation and uninstallation, see README.md.

 VERSIÓN EN CASTELLANO

¡Gracias por descargar WMM!

WMM es un gestor de fondos de pantalla para configuraciones multi-monitor
en Linux y Windows, compatible con Cinnamon, GNOME Shell, KDE Plasma 6,
MATE y XFCE.

ENTORNOS SOPORTADOS
------------------

  - Cinnamon:       Soporte completo (X11)
  - GNOME Shell:    Soporte completo (versiones 45 a 51)
  - KDE Plasma 6:   Soporte completo
  - MATE:           Soporte completo (X11)
  - XFCE:           Soporte completo (XFCE 4.20 / X11)
  - Windows:        Soporte completo
  - macOS:          En desarrollo

INSTALACIÓN RÁPIDA
------------------

LINUX

1. Abre una terminal en la carpeta que contiene wmm-install.sh.

2. Ejecuta:

       chmod +x wmm-install.sh
       ./wmm-install.sh

   El instalador detecta el entorno de escritorio, comprueba las
   dependencias y ofrece instalar las que falten.

3. Después de instalar, activa o inicia WMM:

   - Cinnamon:
     Reinicia la sesión y activa "WMM Manager" en Miniaplicaciones,
     o inícialo desde Menú > Gráficos.

   - GNOME Shell:
     Reinicia la sesión y activa "WMM Manager" en Extensiones,
     o inícialo desde Aplicaciones > WMM.

   - KDE Plasma 6:
     En Plasma 6.6.6 o posterior, el instalador reinicia Plasma Shell.
     En versiones anteriores, reinicia la sesión. Inicia WMM Manager
     desde Menú > Gráficos.

   - MATE:
     Añade "WMM Manager" mediante Añadir al panel, o inícialo
     desde Menú > Gráficos.

   - XFCE:
     Inicia WMM Manager desde Menú > Gráficos.

WINDOWS - OPEN-CODE

1. Descarga el código de WMM desde GitHub y descomprímelo en una carpeta.

2. Ejecuta wmm-install.cmd desde la carpeta principal, selecciona
   Instalar y confirma la operación.

3. Si falta wmm-runtime.zip, el instalador ofrece descargarlo desde
   GitHub cuando esté disponible. También puedes descargarlo por separado
   y colocarlo junto a wmm-install.cmd antes de comenzar.

4. Sigue las indicaciones. Al finalizar, inicia WMM Manager desde el
   menú Inicio de Windows. También puedes elegir un acceso directo
   en el escritorio y el inicio automático.

WINDOWS - VERSIÓN COMPILADA

1. Descarga WMM-Manager-Setup desde la publicación correspondiente.

2. Ejecuta el instalador y sigue los pasos del asistente.

3. Inicia WMM Manager desde el menú Inicio o su acceso directo.

   Incluye todos los componentes necesarios; no hace falta descargar
   el runtime por separado.

Para actualizar, reinstalar o desinstalar WMM, consulta README.md.
