To make Online search more accessible, WMM uses either a public API or a key shared among its users, depending on the provider. This allows you to enjoy the service without configuring a personal key, although usage limits may depend on the combined activity of all users.
If you regularly use Online search, we recommend obtaining your own API key. It is free from the providers available in WMM and gives you an independent usage allowance, without relying on the shared quota.
This way, we can all contribute to responsible use, respect the limits established by the providers, and help preserve the availability of the services they make available to us.

────────  How to use your API key  ────────

- Once you have obtained your API key, save it in a plain text file (.txt) in a location accessible to WMM.
- Then use the corresponding provider's button to link the file.

WMM does not store your API key in its configuration.
It simply accesses the file when the key is needed to make requests to the provider.
